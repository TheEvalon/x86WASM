# Machine model ? PC v1

Classic PC subset for firmware and OS bring-up. See ADR `docs/adr/0001-machine-model.md`.

## Memory (Milestone 1 lab)

- Contiguous RAM from physical `0` (default size configurable; CLI default 16 MiB).
- ROM window mapped at `0xFFFF_0000` (64 KiB) so the Intel reset vector at `CS.base + 0xFFF0` = `0xFFFF_FFF0` fetches ROM.
- Optional alias of the same ROM image at `0x000F_0000` for real-mode `F000:xxxx` tooling later.
- A20 gate on `PhysMem`: when disabled, physical address bit 20 is forced clear on CPU bus read/write. Controlled by 8042 output-port bit1 (`0xD1` write / `0xD0` read). Reset default: A20 enabled.

## MMIO

- VGA color text plane: physical `0xB8000`–`0xBFFFF` (32 KiB) owned by `devices::VgaText` on the CPU data bus (`MachineBus` intercepts before `PhysMem`). Attribute Controller: write address then data to `0x3C0` via internal flip-flop, read data at `0x3C1`, read address at `0x3C0` (no flip-flop toggle); indexes `0x00`–`0x14` with mode-03h reset defaults palette `00/01/02/03/04/05/14/07/38/39/3A/3B/3C/3D/3E/3F`, Mode Control=`0x0C`, Overscan=`0x00`, Color Plane Enable=`0x0F`, Horizontal PEL Panning=`0x08`, Color Select=`0x00`; address default `0x20` (PAS); Input Status #1 read (color `0x3DA` when Misc IOAS=1, mono `0x3BA` when IOAS=0) resets flip-flop and returns Display Disabled (bit0) / Vertical Retrace (bit3) via a deterministic read-phase counter (even = active `0x00`, odd = VR+DD `0x09`; not CRTC-timed; inactive alias not owned). DAC/PEL: PEL Mask `0x3C6` R/W (reset default `0xFF`; store/readback; display-path pixel-index AND deferred until host render; does not alter `0x3C9` programming), write index `0x3C8`, data `0x3C9` (R→G→B, 6-bit component mask, auto-increment after blue), read index write / DAC State read `0x3C7` (state `00` read-ready / `03` write-ready); 256×3 RAM; reset defaults indices `0`–`15` = classic CGA/EGA 6-bit 16-color palette, `16`–`255` = black (store/readback only). **Not yet:** ATC→DAC remap, blink/PEL pan, PEL Mask display AND, ATC/Sequencer/GC side effects, CRTC-timed Input Status #1 / VR IRQ, Misc clock-select/polarity, full CRTC timing/blanking (Protect write-gate only), host cursor glyph from start/end scanlines, Start Address scroll/pan side effects, planar graphics, VBE, host rendering.
- IDE: legacy primary + secondary fixed ports (no PCI BARs).

- Hardware IRQ path: `MachineBus::poll_external_irq` syncs PIT ch0 OUT â†’ IRQ0, 8042 OBFâˆ§INT1 â†’ IRQ1, CMOS IRQF â†’ IRQ8, 8042 AUX OBFâˆ§INT12 â†’ IRQ12, primary IDE INTRQâˆ§Â¬nIEN â†’ IRQ14, and secondary IDE â†’ IRQ15 then `DualPic::poll_irq` (INTA-style acknowledge + vector). - 8259A dual PIC: port-wired on `MachineBus`; ICW1â€“ICW4 (incl. ICW1.LTIM level-triggered runtime â€” IRR follows IR level; deassert clears IRR; acknowledge while IR still high re-pends IRR so EOI can re-deliver without a new edge; ICW4.AEOI Automatic EOI â€” ISR bit cleared at end of INTA / OCW3-poll acknowledge; ICW4.SFNM Special Fully Nested Mode on master â€” slave-connected IS bit does not lock cascade IR out of master priority logic so higher-priority IR on same slave can deliver without master EOI; ICW1 clears SFNM), OCW1 IMR, OCW2 non-specific/specific EOI, OCW2 Automatic Rotation (Rotate on Non-Specific EOI + Rotate in Automatic EOI Mode set/clear; rotated lowest_priority drives resolver / nested blocking / non-specific EOI; ICW1 resets bottom to IR7 and clears rotate-in-AEOI), OCW2 Specific Rotation (Set Priority Command `R=1,SL=1,EOI=0` + L2â€“L0 â†’ lowest without EOI; Rotate on Specific EOI `R=1,SL=1,EOI=1` + L2â€“L0 clears named ISR and assigns that IR lowest), OCW3 IRR/ISR read select, OCW3 poll command, OCW3 Special Mask Mode (`ESMM`/`SMM` â€” masked in-service IR does not nested-block lower unmasked IRQs; non-specific EOI skips masked IS bits; ICW1 clears SMM), edge IR assert (LTIM=0), spurious / DEFAULT IR7 when IR pin is low at first INTA (vector IR7, ISR bit7 not set; real IR7 sets ISR bit7; master cascade IR never remapped â€” empty/spurious slave still sets master cascade IS), fully nested priority, cascade on IR2. **Not yet:** host-visible INT-raise vs INTA race beyond pin-low-at-ack / empty-slave-cascade model.
- 8259A OCW3 poll command (`P=1`): writing OCW3 with `P=1` to a command port (`0x20` master / `0xA0` slave) arms that chip; the **next read of that command port** is an interrupt-acknowledge cycle instead of an IRR/ISR read. It resolves the highest-priority unmasked request (fully nested or Special Mask Mode rules, IMR applied), sets that IS bit, clears/re-pends the IR bit via the shared `ack_ir` path (edge clears IRR; level re-pends while IR stays high; DEFAULT IR7 reports level 7 without setting ISR bit7), and returns `0x80 | level` (bit7 = interrupt pending, bits 2:0 = binary level). With ICW4.AEOI the IS bit is cleared again at the end of that acknowledge (same `ack_ir` path as hardware INTA). The poll is one-shot: later command-port reads return the `RR`/`RIS`-selected register again, and `P=1` leaves that selection untouched. Cascaded polling is software sequenced â€” poll the master (returns cascade level 2 on the PC AT and sets master IS2), then poll the slave command port for the slave level. With nothing pending the byte is `0x00`; bits 2:0 are unspecified by the datasheet in that case, so **zero is a documented model choice**. Reset / ICW1 state: poll disarmed (a fresh OCW3 `P=1` is required after every ICW1 sequence).
- 8254 PIT: port-wired on `MachineBus`; channel-0 programming + `ce`/OUT tick (`Pit8254::tick_ch0`, `Machine::tick_pit` also ticks ch2). Modes 0â€“5 move OUT; OUT rising edges drive IRQ0 (8259A master IR0). Mode 0 OUT rises at terminal count; modes 2/3 pulse OUT low one clock per period; modes 4/5 strobe OUT low for one clock at terminal count (one-shot: mode 4 re-armed by a new count, mode 5 by a GATE rising edge); mode 1 drives OUT low on the GATE trigger until terminal count (retriggerable). GATE low disables counting in modes 0/2/3/4 (forcing OUT high in modes 2/3) and has no effect in modes 1/5. Ch0/ch1 GATE assumed high, so GATE-triggered modes 1/5 only start counting on channel 2. Channel 2 GATE + speaker-data latch + OUT2 readback via port `0x61` bits 0/1/5 (no host audio). Read-Back command on control port `0x43` (`SC=11`): COUNT=0 / STATUS=0 latch selected counters' count and/or status; status byte is OUT | NULL COUNT | RW | M | BCD; when both are latched the first data-port read returns status then the programmed access-width count bytes; unread latches are not overwritten by later latch commands. Guest wall-clock rate is **not** host-real-time (explicit tick quantum). **Not yet:** host speaker audio, ch1 DRAM refresh, mode 3 exact 50% duty, one-CLK count-load/trigger delay (loads take effect on the same model clock; NULL COUNT clears on that same clock), BCD counting during tick, port `0x61` NMI/parity/refresh bits.
- CMOS/RTC: port-wired on `MachineBus`; status B PIE/AIE/UIE + status C PF/AF/UF/IRQF (read-to-clear); `CmosRtc::tick` / `Machine::tick_cmos` â†’ IRQ8 (8259A slave IR0); Status A UIP + `CmosRtc::tick_second` / `Machine::tick_cmos_second` full BCD calendar update cycle (SET inhibits); port `0x70` bit7 NMI mask stored (`CmosRtc::nmi_masked`) / `Machine::nmi_delivery_enabled`; `Machine::inject_nmi` latches CPU `#NMI` (IVT vector 2) when unmasked, drops when masked. Guest period/second quantum is **not** host-real-time.
  - Time/calendar register map: `0x00` sec, `0x01` sec alarm, `0x02` min, `0x03` min alarm, `0x04` hour, `0x05` hour alarm, `0x06` day of week (1 = Sunday â€¦ 7 = Saturday), `0x07` date of month, `0x08` month, `0x09` year, `0x0A`â€“`0x0D` status Aâ€“D, `0x32` century (PC/AT + ACPI FADT convention, not part of the MC146818 file).
  - Update-cycle cascade (each `tick_second` when status B SET=0): sec `0x59`â†’`0x00` â†’ min `0x59`â†’`0x00` â†’ hour `0x23`â†’`0x00` â†’ date of month per actual month length (February 29 in Gregorian leap years computed from century+year) â†’ month `0x12`â†’`0x01` â†’ year `0x99`â†’`0x00` â†’ century `0x32`. Day of week advances 1â€“7 (wrapping 7â†’1) on every date rollover, independent of the month/date arithmetic.
  - Reset state: all 128 bytes zero except status A `0x26`, status B `0x02` (BCD, 24-hour), status C `0x00`, status D `0x80` â€” i.e. time/calendar/century zeros, which are **not** a valid date.   - **Not yet:** host wall-clock/NTP sync, SMRAM/SMI / NMI nesting, exact crystal UIP pulse width, binary (status B `DM`) data mode and 12-hour mode conversions (BCD/24-hour only), square-wave output, ACPI extended CMOS beyond 128 bytes.
